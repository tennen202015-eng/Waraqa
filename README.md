# ورقة · Waraqa

أدوات الصور وملفات PDF في مكان واحد. كل المعالجة تتم داخل المتصفح على جهازك، ولا تُرفع الملفات لأي خادم.

## المميزات

**تعديل وتنظيم PDF**
- تعديل PDF: نص، توقيع محفوظ، قلم، تظليل، إخفاء، مستطيل، سهم، صور مع القص وتغيير الحجم بالسحب
- ورق رسمي (ليتر هيد): شعار، ورأس وتذييل بالكتابة أو الصورة، مع معاينة مباشرة
- دمج، تقسيم، ترقيم الصفحات، علامة مائية بالكتابة أو بالشعار، توحيد مقاس الصفحات

**ضغط وحماية**
- ضغط PDF بأربعة مستويات، وفك الحماية

**التحويل**
- PDF إلى Word وExcel وPowerPoint وصور وMarkdown وHTML وCSV ونص
- Word وExcel وCSV وMarkdown وHTML والصور إلى PDF
- تحويل الصور بين JPG وPNG وWEBP وGIF وBMP وICO وTIFF وAVIF، مع الضغط وتغيير المقاس وضبط الألوان
- صور إلى GIF متحرك

**بالذكاء الاصطناعي** (تعمل عند فتح الصفحة داخل Claude فقط)
- ترجمة الملفات، استخراج النص من الصور (OCR)، تلخيص الملف وسؤاله

## التشغيل

افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع:
Settings ← Pages ← Branch: `main` ← حفظ.

تحتاج الصفحة اتصالاً بالإنترنت لتحميل المكتبات (pdf.js وpdf-lib وغيرها).
